# 🌐 Nexora Website

A modern and responsive frontend website designed with a clean, professional, and user-friendly interface.

Nexora was built using **HTML5 and CSS3**, with a focus on modern web design, responsive layouts, visual consistency, and a smooth browsing experience.

- User-friendly browsing experience

Nexora was created as a frontend development project to strengthen my practical skills in building clean, modern, and responsive websites using HTML and CSS.
